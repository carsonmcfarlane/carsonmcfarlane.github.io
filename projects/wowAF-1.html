Project: Custom Tooltip Refactor in AuctionFaster – Overcoming WoW Classic Client Changes (TBC Anniversary / WotLK Era)

Key personal contributions (marked in code comments as "My changes only"):

  • Refactored the Inventory module to eliminate dependency on the outdated LibGratuity-3.0 and implement a robust, self-contained tooltip scanner.
  • Implemented a custom tooltip creation and scanning mechanism that directly interacts with the WoW API, ensuring compatibility with the latest client changes.
  • Added comprehensive error handling and fallback logic to gracefully manage edge cases where tooltip data may be incomplete or delayed.
  • Conducted extensive testing across various item types (soulbound, BoP, quest-bound, conjured) to validate the accuracy and reliability of the new tooltip scanning approach.
  • Removed LibGratuity-3.0 usage entirely (commented out LibStub load and all :SetBagItem(), :NumLines(), :GetLine() calls) to avoid compatibility failures.
  • Added a single, reusable hidden tooltip frame created once at module scope:
